# Statistics Practicals (`stat-prac`)

This repository is made to revise codes on the go while going to college.

## Contents

- **`exp1.py`**: Dataset inspection & descriptive statistics (summary statistics, histograms).
- **`exp2.py`**: Missing value imputation, feature encoding, and scaling.
- **`exp3.py`**: Sampling techniques (simple random sampling, stratified sampling).
- **`exp4.py`**: Hypothesis testing (T-tests, Chi-square tests, ANOVA).
- **`exp6.py`**: Multiple linear regression analysis, VIF, and model evaluation.
- **`exp8.py`**: Classification models (Logistic Regression, KNN, Naive Bayes) and evaluation metrics.
- **`exp9.py`**: Tree-based classification (Decision Trees, Random Forest) and feature importance.
